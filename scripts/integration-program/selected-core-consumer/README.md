# Selected Core runtime consumer fixture

This fixture reproduces the original `VariableScopingWorkflow` behavior from `test/integration/Elsa.Activities.IntegrationTests/SetVariableTests.cs`. Its source was pinned and compared at Core 3.8 commit `33181ae3048f628f591a0155b5665a8e4d1bcea2` (tree `7ab70135ea43fc6e93c6cb26b9d0df2d91b20b85`) and Core 3.9 commit `5d3582b6309a2fd8ea33ebdb8c39fb040bfdc514` (tree `59d5cf6d6f2ce378c4b3fd888238abe2a9541561`). Both pins have the same original test and fixture body. The test expects the nested `Foo` variable to produce the single standard-output line `Sequence Value`.

The fixture builds default Elsa services with `AddElsa`, configures `UseWorkflows` and `WithStandardOutStreamProvider` to capture output in a `StringWriter`, initializes registries through the runtime's `IRegistriesPopulator` (the underlying service used by the original test helper's `PopulateRegistriesAsync`), and invokes the real `IWorkflowRunner.RunAsync<VariableScopingWorkflow>()`. It checks the exact output, `WorkflowStatus.Finished`, `WorkflowSubStatus.Finished`, and zero incidents before taking the shared `SelectedAssemblyProof.Snapshot()` and writing the selected-consumer proof record. `Finished` is the successful sub-status in both pinned source versions; neither defines `Completed`.

The fixture is intended to be compiled and run later against one exact `Elsa` package reference and the retained package archives selected by the release plan. It reuses `scripts/integration-program/selected-consumer/AssemblyProof.cs`; it adds no package reference, project file, test-helper dependency, or optional expression/scheduling feature. This implementation checkpoint did not build, restore, or execute the fixture, so compile-time and runtime compatibility with the retained archives remains unverified. The evidence scope is a small synchronous in-memory run covering nested variable scope, assignment, and output; it makes no claim about persistence, resume, distributed execution, HTTP, Studio, Extensions, or hosted providers.
