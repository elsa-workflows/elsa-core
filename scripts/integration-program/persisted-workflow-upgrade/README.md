# Persisted workflow package upgrade proof

This nonpublishing fixture upgrades actual Elsa 3.8.4 and 3.9.0 SQLite workflow state directly to the verified consolidated candidate on the same framework. All six combinations with net8.0, net9.0 and net10.0 must pass. A development `--cell 3.8.4/net8.0` run records `complete_matrix: false` and cannot satisfy the matrix gate.

```sh
python3 -m unittest discover -s scripts/integration-program -p test_persisted_workflow_upgrade_fixture.py
python3 scripts/integration-program/run_persisted_workflow_upgrade_fixture.py \
  --proof-artifacts /absolute/path/to/extracted-original-proof \
  --proof-archive /absolute/path/to/original-proof.zip \
  --output /absolute/path/outside-checkout/new-evidence-directory
```

Install the .NET 8, 9 and 10 SDKs/runtimes and Python 3.10 or later. The output directory must not already exist. Baselines resolve from NuGet.org and require their released nuspec source commits.
